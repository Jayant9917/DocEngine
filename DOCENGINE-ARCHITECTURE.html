How DocEngine fits together

A client uploads a CSV, the API queues a report job, and a worker creates the result in the background. Monitoring runs alongside the application.

The default view shows the full system. Select a service or trace a flow to highlight it.

Request and storage

The API handles upload and job requests. PostgreSQL keeps job state; MinIO keeps file contents.

Background work

RabbitMQ hands jobs to workers. Workers atomically claim jobs, create reports, store outputs, and update status.

Monitoring

Prometheus pulls API/worker metrics. Grafana reads those metrics and renders the dashboard.
